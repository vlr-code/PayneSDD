# PayneSDD для Codex

Отдельный экземпляр на основе PayneSDD v2.0.2. Девять шагов и Joe сохранены
дословно; добавлены инструкции для среды Codex. Оригинальные файлы Claude
не меняются. Это локальная адаптация 1, не новый релиз исходного протокола.

## Состав

- [DIGEST.md](DIGEST.md): обязательный протокол и работа с инструментами Codex.
- [PREFERENCES.md](PREFERENCES.md): простой язык, Joe, нулевой след, исключение homework.
- [MAINTAINING.md](MAINTAINING.md): изменения этой версии и dev mode.
- [payne-edit](skills/payne-edit/SKILL.md) и [payne-review](skills/payne-review/SKILL.md): навыки.
- [payne-quality](agents/payne-quality.toml): независимый проверяющий.
- [Проверки](evidence/validation.md) и [условия сравнения GPT](evidence/reading-rule.md).

## Установка

Из корня PayneSDD после согласия пользователя:

```bash
python3 codex/scripts/install.py
```

Установщик заменяет только старый раздел PayneSDD в `~/.codex/AGENTS.md` на
инструкцию явно прочитать живые файлы из `codex/`. Остальные разделы сохраняет.
Если раздела нет, добавляет свой блок. До замены сохраняет исходный файл в
`~/.codex/payne-backups/<sha256>.AGENTS.md`. При неоднозначном блоке, чужой ссылке
или активном `AGENTS.override.md` останавливается без изменения настроек.
Не меняет `config.toml`, выбранную модель, настройки Claude или проекты.

Создаёт живые ссылки в `~/.agents/skills/payne-edit`, `~/.agents/skills/payne-review`
и `~/.codex/agents/payne-quality.toml`. Маркер `~/.codex/.payne-dev-mode` содержит
путь к этому экземпляру. Повторная установка сохраняет выключенный dev mode.
`CODEX_HOME` переопределяет каталог настроек; `--skills-home` — каталог навыков.

Открой новый чат Codex, чтобы загрузились глобальные инструкции. Можно попросить:
«Прочитай подключённый PayneSDD и назови путь к протоколу, режим и команды».
Ожидается чтение файлов `PayneSDD/codex/`, а не заявление об автоматическом `@`-импорте.
Старый открытый чат может хранить прежние инструкции.

## Использование

`$payne-review` — независимый разбор текущих изменений.
`$payne-edit status`, `$payne-edit on`, `$payne-edit off`, `$payne-edit inbox` — dev mode.
Можно просить то же обычными словами. Slash-команды Claude не устанавливаются.
Если у сессии нет инструмента субагентов, обязательный независимый разбор остаётся
непроверенным: протокол требует ESCALATE, а не имитацию второго проверяющего.
В проверенной CLI 0.163.0-alpha.10.2 вызов именованной роли payne-quality вернул
`agent type is currently not available`. Навыки в этом случае передают её
инструкции обычному отдельному субагенту; наличие TOML само по себе не считается
доказательством работы роли. Экспериментальные настройки CLI не переключаются.

## Проверки и возврат

```bash
bash codex/scripts/check.sh
```

Запускает исходную родную проверку, тесты установщика и целостности новой версии.
Сверка контрольных сумм фиксирует неизменность Claude-файлов на момент переноса;
после отдельного согласованного обновления Claude нужно явно обновить базу сравнения.
Поведенческое сравнение отдельно: `python3 codex/scripts/compare.py`; оно расходует
запуски модели и сохраняет результаты во временной папке. Это малая проба, не
статистическая гарантия качества или экономии токенов.

Для возврата сначала сравни текущий `AGENTS.md` с резервной копией: если после
установки появились другие правки, восстанови только раздел PayneSDD. Полную копию
возвращай лишь при отсутствии таких правок. Затем по запросу пользователя убери
только ссылки, указывающие в этот `codex/`, и его маркер. Исходник Claude не затронут.
