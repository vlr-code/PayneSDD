# Проверка адаптации Codex — 2026-10-17

Статус: сравнение GPT принято по малой пробе; установлен отдельный экземпляр.
Итог полного гейта после последнего независимого разбора сообщается при сдаче.

## Карта критериев

- Claude остаётся прежним → SHA-256 всех исходных отслеживаемых файлов в
  [claude-baseline.json](claude-baseline.json); любое изменение провалит validate.py.
- Настройки пользователя сохраняются → test_install.py проверяет разделы до и
  после PayneSDD и точные байты резервной копии.
- Повторная установка и выключение → тот же тест проверяет неизменность текста,
  живые ссылки и сохранение выключенного маркера.
- Ошибка установки → конфликт и искусственный отказ записи; исходный файл цел,
  новые ссылки и маркер откачены.
- Проверки способны находить поломку → [red-proof.txt](red-proof.txt): все пять
  методов тестов упали на соответствующей поломке временной копии установщика.
- Проверки модели нельзя ослабить → [oracle-proof.txt](oracle-proof.txt): пустые
  тесты в папке агента не скрывают неверную функцию; тест регрессии тоже видел красный.
- Поведение GPT → [reading-rule.md](reading-rule.md) и [gpt-smoke.json](gpt-smoke.json).
  В каждой версии оба первых хода оставили файлы без изменений; Light после
  согласия прошёл неизменяемый oracle, агент сам запустил unittest и дал PASS;
  Full обозначил риск повторного списания и запросил недостающие сведения.
- Обнаружение и чтение в новой сессии → явно прочитаны три файла протокола и
  payne-edit; status вернул ON, оба навыка обнаружены. Именованная роль вернула
  `agent type is currently not available`; повторная интеграционная проба запустила
  обычного независимого субагента с теми же инструкциями и получила SHIP по узкому
  контракту. В потоке событий есть завершённое ожидание; итог и источники сохранены
  в [activation.json](activation.json). Отказ имени роли не объявлен её успешным запуском.
- Независимый разбор → раунд 1: SHIP по первой реализации; раунд 2: исправлена
  независимость oracle. Последний разбор читает эту правку и окончательные доказательства;
  его вердикт, затем результат полного гейта фиксируются в итоговом сообщении.
- Полная проверка → `bash codex/scripts/check.sh` после последнего разбора, отдельно.

Целевые проверки: 5 тестов test_install.py и один test_compare.py прошли;
validate.py прошёл. Оба навыка проверены штатным quick_validate.py (Skill Creator),
TOML проверяющего разобран tomllib Python 3.12 без ошибок.
Первый запуск CLI из внешней песочницы не дошёл до модели: readonly database /
Operation not permitted. Повтор запущен с разрешением на доступ CLI к своей базе;
дочерние агенты сохраняют workspace-write, обход разрешений не применяется.
Проба после разрешения также отброшена: project_doc_max_bytes=0 не исключил
глобальный AGENTS.md, и агент прочитал исходный протокол. До принятого прогона
изоляция усилена отдельным временным CODEX_HOME и проверкой входного контекста.
Следующий прогон выявил другую ошибку стенда: exec resume вернулся к read-only.
Агент честно сообщил ESCALATE; это не провал протокола. Прогон отброшен, режим
workspace-write теперь задаётся явно и при продолжении. Принят третий рабочий
запуск: gpt-6-astra/high, исходный и адаптированный тексты, по одному повторению
двух сценариев, шесть ходов модели. Выходы CLI и родных тестов — 0. Состояние
папок проверено снимками файлов; transcript audit выполнен вручную по сохранённым
событиям. После замечания раунда 2 исходный oracle отдельно повторён для обоих
готовых решений в новой папке: оба прошли. Порог приёмки не менялся.

## Границы доказательств

Статические проверки не доказывают соблюдение протокола моделью. Малая проба GPT
не измеряет надёжность на всех задачах или экономию. Известное напряжение §2/§7
сохранено по исходным решениям; адаптация не возвращает отвергнутые v209/v210.
