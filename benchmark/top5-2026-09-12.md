## The honest half

**The consent carve-out never fired.** All sixteen counted consents in the
candidate arm were ordinary questions, not the "your words are the plan" echo —
on this suite the agent never judged a task prompt to be the whole plan. So the
run shows the carve-out did no harm; it does not show it helps. Its four source
cases are a human's message inside a live conversation, which a two-turn harness
does not reproduce.

**Two fixes are not exercisable here either.** "A check born of a finding is
ratcheted" needs a reviewer finding inside the run, and "re-read the destination
before an irreversible act" needs a second writer and a real push. Both ship on
their source evidence and the gate, not on this epoch.

**The probe was taught the echo line BEFORE the run** and symmetrically for both
arms (fixtures F14, verified red against the old rule), because the old probe
scored the carve-out's correct behavior as a failure. The trap task deliberately
uses the strict measure, which never accepts an echo.
