# Second inbox batch, and the noise that came with it (2026-09-12)

Five clauses from the dev-mode inbox (evidence stamped to the state it measured,
a required NOT CHECKED line in reviewer reports, your own infrastructure in the
irreversible list, black-box gating by controlled experiment, pinned decisions
in the analyst brief). Machine-readable aggregate: `batch2-2026-09-12.json`.

## The run

Base (the protocol as shipped) against base-plus-the-five, twelve blind tasks
plus the D13 trap, two runs per cell, 52 runs, 0 indeterminate, acceptance
pre-registered before launch.

PASS on the pre-registered bar (worst −2); the trap held at 2/2 on both sides.

## The part that matters more than the pass

The reviewer read the drift between two epochs as same-text noise. The payload
hashes said otherwise — the two texts differed — so the −2 had no noise estimate
behind it. We then measured one: the SAME base payload, re-run alone.

| dimension | base, run 1 | base, run 2 — identical text | drift |
|---|---|---|---|
| asked for consent | 12/18 | 8/18 | **−4** |
| wrote nothing before consent | 14/18 | 10/18 | **−4** |
| closing summary in shape | 15/16 | 14/16 | −1 |
| ran a verification command | 9/16 | 9/16 | 0 |
| named the tier | 19/24 | 19/24 | 0 |
| task outcome | 21/22 | 21/22 | 0 |

**The acceptance bar sits inside the noise.** A −3 rule cannot judge a family of
dimensions that moves ±4 on identical text at two runs per cell. Read every
consent-family number in this repo's 2026-09 snapshots with that in mind: large
rejections (−9, −10) are still safe, a −3 or −4 verdict is not.

`gate_ran` is the exception here: it did not move at all between the two base
runs, so the candidate's −2 stays on the record as unexplained rather than
waved away as noise. It is the dimension the new Step 4 obligations load, and
Step 4 grew by about a third today.

## What this does not measure

One noise pair on one suite and one model: a drift estimate, not a band. None of
the five clauses is exercisable here — no second writer, no push, no external
system, no live reviewer — so this run is a no-regression check only, never
evidence the clauses work.
